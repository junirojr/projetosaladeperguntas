O que vai ser a aplicação? 
	Um conjunto de salas, onde cada sala terá senha e identificação. 
	Cada sala deve ser um ambiente onde as pessoas que participam podem se comunicar, criar posts, curtir os posts e comentar. 

Formato - 
	1 - Página de Login/cadastro
		pagina de cadastro
	2 - Página inicial onde mostram todas as salas do usuário. 
	3 - Página da sala.
		3.1 - Pagina de iniciar post
		3.2 - Pagina do post (Opções de curtir e comentar)
	4 - Página do perfil do usuário.
	
	
Tecnologias - 
	C# - Backend 
	Next.JS + Tailwind - FrontEnd
	Banco de dados - a escolher.
	

1 - A aplicação deve ter comunicação com algum banco de dados, para armazenar usuários, posts, comentários
